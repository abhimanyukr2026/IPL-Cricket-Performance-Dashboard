IPL Cricket Performance Dashboard

Project Overview

This project is an IPL Cricket Performance Dashboard created using Microsoft Power BI.

It provides insights into IPL team performance through interactive charts and KPI cards.

Tools Used

- Microsoft Power BI
- Data Visualization
- Data Analysis

Dashboard Features

- Total Matches
- Total Team Runs
- Total Team Wickets
- IPL Team Runs Analysis
- IPL Team Wickets Analysis
- Interactive Team Slicer

Project Objective

To analyze IPL team performance and present cricket statistics through an interactive dashboard.
